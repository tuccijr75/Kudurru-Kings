# Milestone ladder

| Milestone | Implement | Gate |
|---|---|---|
| M0 | Source authority / original EOE integration ledger | No shared-lore drift; no private Bible in public repo |
| **M1 ACTIVE** | Godot scene, four seats, phase-state reducer, deck/capture gates, tests | Godot parses, opens, tests pass |
| M2 | Card schema normalizer, Crosswalk reconciliation, certified catalog, deck builder | Verified owner factions; reviewed costs; negative legality tests |
| M3 | Match setup, scenario, 6-card opening hand + mulligan, determinism/replay | Seed and action sequence yield matching event hash |
| M4 | Fields/Lines/Geasa, axes, Face-off, supporters, wounds, states | Golden combat cases/softlock tests |
| M5 | Optional Resolution capture, Boss Trials, Arbitration, raids, 10 Marks | Zero double scoring, no unauthorized collection copies |
| M6 | All eight card families, solo AI, meaningful complete match | 100 seeded solo matches reach legal conclusion |
| M7 | 2–4 player authoritative networking, concealment, reconnect | No hidden-data leaks and deterministic sync |
| M8 | Shards/Sigils/Fragments, rarity, rewards, persistence | Idempotent payouts, anti-abuse tests |
| M9 | Accessibility, usability, performance, packaging, release QA | Explicit owner release approval |

Approval required for: undefined pure-faction perks, card deployment costs, conflicting entity identity, unresolved capture mechanics, production multiplayer architecture, economy changes, and public release. Existing rules and EOE world facts are not reauthored by engineering.
